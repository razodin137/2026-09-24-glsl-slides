One canvas, two languages

SVG + CSS — the foreground

Meaning: type, icons, diagrams. Vector-crisp at any zoom, inspectable, styleable.

GLSL — the atmosphere

One fragment shader per scene. Per-pixel light, motion and texture that CSS can't reach.

Post FX — the finish

Grain, aberration, halftone, grids, vignette — chained math on the same framebuffer.

The DOM stays semantic. The GPU stays beautiful. Neither layer knows the other exists.

Every pixel is a function call

No textures. No video. No image assets. Eleven scenes, one fragment shader — a few hundred lines of math, resolved two million times per frame.

Compositing is cheap

Each effect is a few lines of math on the same framebuffer. Chain them in order: quantize → aberrate → halftone → grid → vignette → grain.

House style: code as prose

A pleasure to read

Order code by invocation. A reader should follow the whole flow top-down, no jumping.

Abstractions earn their keep

No third variation, no helper. Inline until the code itself asks for a seam.

Explicit over clever

An if-chain of eleven scenes beats a reflective registry. Expanded conditionals over guard clauses.

Compute at write time

Bake shader strings. Measure paths once. Never rebuild per frame what you can build at load.
